# Concepts

## Primary intent

The main job the user came to complete. A screen should have one dominant intent whenever the product allows it.

## Secondary intent

Supporting needs that help the primary decision, such as checking delivery before buying. They should not compete with the primary action.

## Dominant object and action

The information/object that must be perceived first and the next action the interface should make obvious, semantic and predictable.

## Attention hierarchy

The mapping between product importance and visual weight. Size, position, contrast, color, whitespace and motion all spend attention. A lower-priority element that is louder than a primary action is a UX defect.

## Decision architecture

The sequence of information and actions that lets a user perceive, understand, trust, decide, act and confirm with the fewest unjustified mental choices.

## Friction

Any unnecessary click, field, choice, ambiguity, context switch, wait or recovery cost. More clicks are not automatically worse when a step prevents error or overload.

## Progressive disclosure

Layer information by need: perceive, decide, confirm, explore and advanced detail. Do not hide evidence required for trust merely to make a screen look clean.

## Trust architecture

The evidence, clarity and control needed for a user to make a consequential decision confidently: price, conditions, delivery, seller, protection, errors, permissions and consequences as applicable.

## UX Lint

A vocabulary for actionable findings such as `UX-ATTENTION`, `UX-CTA`, `UX-FRICTION`, `UX-DENSITY`, `UX-NOISE`, `UX-NAV`, `UX-TRUST`, `UX-CONTEXT`, `UX-HIERARCHY`, `UX-COPY`, `UX-DECORATION` and `UX-PATTERN`.

## Density vs confusion

Density is how much information exists. Confusion is failure of hierarchy, grouping, language or orientation. A dense page can be efficient; an empty page can still be unusable.

## Every pixel pays rent

If something occupies space, draws attention, requires a click, uses color, animates or adds copy, it must help the user understand, decide, trust, navigate or act.
